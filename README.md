# VMY2026 AI Assistant & Power BI Analytics Dashboard

An interactive AI-powered assistant designed for the Visit Malaysia Year (VMY2026/2027) Power BI dashboard.

## Features
- **Time-Series Forecasting:** Visualizes arrival trajectories through 2027 (Meta Prophet / SARIMAX).
- **Readiness Scoring:** Assesses state carrying capacity via PCA and quadrant modeling.
- **Natural Language Querying:** Answers tourism metric queries powered by DeepSeek AI via Gonka.

## Tech Stack
- **Frontend / Deployment:** Streamlit, Power BI HTML Content Visual
- **Machine Learning:** Scikit-Learn, Meta Prophet, Pandas
- **AI Integration:** OpenAI / Gonka Router API
